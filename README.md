====================================================
OVER CARITAS BOAZ
====================================================

Caritas BOAZ is een charitatieve instelling van de rooms-katholieke geloofsgemeenschap die hulp biedt aan mensen in nood.

De organisatie zet zich in voor mensen die te maken hebben met tijdelijke financiële of persoonlijke nood.

Caritas BOAZ is actief binnen de parochies en lokale gemeenschap van:

Bloemendaal
Overveen
Aerdenhout
Zandvoort

BOAZ staat voor:

Bloemendaal
Overveen
Aerdenhout
Zandvoort

Caritas BOAZ is een kerkelijke rechtspersoon met een eigen bestuur en financieel beheer. De organisatie heeft een sociaal-charitatieve doelstelling en zet zich in voor mensen die tijdelijk extra ondersteuning nodig hebben.

De kern van de organisatie is:

Naar elkaar omkijken.

Mensen helpen wanneer zij tijdelijk in een moeilijke of benarde situatie terechtkomen.

Ondersteuning bieden wanneer reguliere instanties niet voldoende kunnen helpen.

Daarnaast ondersteunt Caritas BOAZ ook lokale maatschappelijke initiatieven en projecten.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
